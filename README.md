# Shop - MongoDB CRUD app

A small web app to create, read, update and delete **Products**, **Customers** and **Orders**.

- Front end: HTML, CSS and JavaScript (`public/index.html`)
- Back end: Node.js + Express (`server.js`)
- Database: MongoDB (database `Shop`)

## Run locally
1. Install Node.js and MongoDB.
2. `npm install`
3. `npm start`
4. Open http://localhost:3000

## Environment variables
- `MONGODB_URI`: MongoDB connection string (for example a MongoDB Atlas URI). Defaults to a local MongoDB.
- `PORT`: set automatically by most hosting services.
